# 手动检查清单

界面部分没有自动化 UI 测试,每次改动界面后按此清单在模拟器或真机上过一遍。

## 首次启动
- [ ] 打开后默认在"记账"Tab,支出分类按顺序是:日用、餐饮、交通、宠物、娱乐、游戏、旅游、汽车、其他、服饰、购物、居住、医疗
- [ ] 切到"收入",分类是工资、奖金、其他收入
- [ ] 杀掉 app 重开,分类没有重复

## 记账页
- [ ] 输入 `12.34`,显示 `¥12.34`;第三位小数按不动
- [ ] 先按 `.` 显示 `¥0.`;连按两次 `.` 只有一个小数点
- [ ] 连按 `0` 不出现 `000`;整数部分最多 7 位
- [ ] 金额为 0 时"完成"不可点
- [ ] 点"完成":轻震动、出现"已记一笔"、金额和备注清空,类型/分类/日期保留
- [ ] 点"餐饮"后下方展开二级分类;只选"餐饮"不选二级也能保存
- [ ] 记过几笔后,"常用"一行出现用得最多的分类
- [ ] 点"昨天",保存后账单页该笔在昨天;再记一笔日期仍是昨天
- [ ] 数字键盘、"完成"按钮是玻璃质感
- [ ] app 切到后台放过午夜,第二天早上回来,没手动选过日期时默认是今天;手动选过"昨天"则保持昨天

## 账单页
- [ ] 顶部汇总的收入/支出/结余与列表一致
- [ ] 左右箭头切换月份,没数据的月份显示"本月还没有账单"
- [ ] 同一天的账单在一组,组标题形如"10月10日 周六"
- [ ] 点一笔进入编辑,改金额/分类/日期/备注后保存生效
- [ ] 编辑时把"支出"切到"收入":分类自动换成收入分类,不会残留餐饮的二级分类和旧的"常用"
- [ ] 左滑删除,底部出现"撤销";点撤销后账单恢复,不点则几秒后消失
- [ ] 快速连点两次"撤销":只恢复一笔,之后点账单行、左滑不会闪退
- [ ] 顶部月份左右箭头:点一下只翻一个月(不会同时触发两个按钮)
- [ ] 在设置里把手机时区改成别的国家再回来看账单:每笔账所在的日子和月份都不变
- [ ] 搜索备注、一级分类名、二级分类名都能命中
- [ ] 右上角菜单:导出当月、导出全部都能调出系统分享面板
- [ ] 把导出的 CSV 用 Numbers 或 Excel 打开,中文不乱码,表头为"日期,类型,金额,一级分类,二级分类,备注"

## 统计页
- [ ] 月/年切换有效,左右箭头翻页
- [ ] 汇总卡片和周期控制条是玻璃质感,背景渐变能透出来
- [ ] 环形图颜色与分类颜色一致,点列表行进入二级分类详情
- [ ] 趋势图:月视图横轴是日,年视图横轴是 12 个月
- [ ] 没有账单的周期显示空状态,不闪退、不出现 NaN

## 设置与分类管理
- [ ] Tab 栏有第 4 个"设置",里面有"分类管理"
- [ ] 游戏下有 原神、ZZZ、steam、暴雪;娱乐下有 电影;汽车下有 停车费、加油
- [ ] 支出/收入切换后列表对应变化;一级分类下缩进显示二级分类
- [ ] 右上角 + 新增一级分类:空名称、超过 10 个字、重名都有提示且不会新增
- [ ] 新增的分类出现在记账页;连续新增 9 个以上,颜色循环,不闪退
- [ ] 点进分类可以改名;改成已有的名字会提示
- [ ] 一级分类里可以新增二级分类;同一个父分类下重名会提示,不同父分类下同名可以
- [ ] 上传图标:从相册选一张横图,图标是居中裁出的正方形;选一张手机竖拍的照片,图标是正的不是躺着的
- [ ] 上传后记账页网格、账单行、分类管理里都显示这张图,是圆形
- [ ] "还原默认图标"后回到原来的 SF Symbol
- [ ] 选一张超过 10 MB 的图,提示"图片太大"
- [ ] 归档一个分类:记账页不再出现;已有账单仍显示原名和图标;"已归档"里能恢复
- [ ] 归档一级分类后,它的二级分类在"已归档"里不单独出现,恢复一级分类后二级分类也回来

## 自动入账(Apple Pay)

模拟器里能看的:
- [ ] 用新版本覆盖旧版本安装后不闪退,已有账单、分类、自定义图标都还在
- [ ] 设置 → 自动入账:能看到六步说明、分类说明和"能覆盖什么"
- [ ] 手动记的账在账单行里**没有**"自动"标记

必须真机验证的(依赖快捷指令和 Apple Pay,Mac 和模拟器上无法确认):
- [ ] 1. 快捷指令里能搜到"记一笔(Apple Pay)"动作,参数是商户和金额(搜不到再补注册 AppShortcutsProvider)
- [ ] 2. 个人自动化里能选"钱包 → 交易",并且能设成"立即运行"(记下 iOS 26 上这几步的实际界面和措辞,据此校正帮助页)
- [ ] 3. 触发器实际传出的金额是什么格式,动作能否解析(不能解析时快捷指令会提示"无法识别金额",把它传出的格式告诉我)
- [ ] 4. app 被杀掉、手机锁屏时刷一次 Apple Pay,账单里出现带"自动"标记的账,备注是商户名
- [ ] 5. app 在前台时触发,没有崩溃,新账立刻出现在界面上
- [ ] 6. 把某个自动账改成某个分类并保存,再刷同一商户,分类自动沿用
- [ ] 7. 免费账号的证书 7 天过期后动作会失效,重装后应能恢复
- [ ] 8. 线上或 app 内的 Apple Pay、Apple Watch 付款是否触发自动化
- [ ] 9. 一笔没有商户名的交易:动作照常记账,备注为空、不报错、不卡住
- [ ] 10. 一笔外币交易:触发器传出的金额是什么,会不会被误记成人民币
- [ ] 删除一笔自动账再点"撤销":恢复后仍带"自动"标记,改它的分类仍会被记住
- [ ] 把一笔自动账的类型改成"收入"再保存:之后同一商户的自动账仍是未分类的支出,不会落进收入分类
- [ ] 手动在快捷指令里运行一次"记一笔(Apple Pay)",商户填"测试"、金额填"12.5":账单里出现 ¥12.50、备注"测试"、带"自动"标记,快捷指令的输出是"已记 ¥12.50 · 测试"
- [ ] 手动运行时金额填"abc":快捷指令提示"无法识别金额",账单里没有新账

## 屏幕识别与通知自动入账(微信、支付宝)

模拟器里能看的:
- [ ] 用新版本覆盖旧版本安装后不闪退,已有账单、分类、自动账都还在
- [ ] 设置 → 自动入账:能看到三个分组(① 钱包 ② 屏幕识别 ③ 通知)、"能覆盖什么"、"隐私"

必须真机验证的(依赖快捷指令、操作按钮、相册和微信支付宝):
- [ ] 1. 操作按钮和轻点背面都能运行"屏幕识别"快捷指令;操作按钮弹出的提示是否会被截进图里(已知会,解析对噪音有容错)
- [ ] 2. "拍摄屏幕截图"运行后,相册和"最近删除"里**都没有新增图片**
- [ ] 3. 微信支付成功页、微信账单页、支付宝账单页的识别文字顺序和格式与样本一致;换一个商户、换一种支付方式后依然能解析
- [ ] 4. 支付宝**支付成功页**的识别文字(采集样本,用于补规则)
- [ ] 5. 通知的两个触发(或合并成一个):筛选生效、立即运行、锁屏时也能运行
- [ ] 6. 在其他 app 里用微信支付或支付宝付款,通知到达后自动入账,账单里是"未分类"、备注是"微信支付"或"支付宝"
- [ ] 7. 在微信、支付宝里直接付款确实**没有**通知(预期行为,由屏幕识别覆盖)
- [ ] 8. 支付宝账单页的分类映射生效("日用百货"记为"日用")
- [ ] 9. 在同一个微信账单页连续触发两次,第二次提示"已记过这一笔"
- [ ] 10. 收入、退款类页面和通知被忽略,不会记成支出
- [ ] 11. 在快捷指令里手动运行"记一笔(屏幕识别)",文字填"今天天气不错":提示"没有识别到支付页面",没有新账
- [ ] 12. 在快捷指令里手动运行"记一笔(通知)",标题填"张三"、正文填"晚上吃什么":安静成功返回"已忽略:不是支付通知",没有新账
- [ ] 删除一笔屏幕识别的账再点"撤销":恢复后仍带"自动"标记,再触发同一个账单页仍提示"已记过这一笔"
