# 成就徽章设计

日期:2026-10-27 · 项目:happy_spending
上位文档:`2026-10-10-bookkeeping-app-design.md`、`2026-10-27-backup-and-restore-design.md`(备份格式的扩展以本文为准)

## 1. 目标与范围

记账最难的是坚持。给坚持管钱的人一点正反馈,但**不打扰**:没有积分、等级,不推送通知;只有一面徽章墙,解锁时 app 内一个小提示。

因为很多账是自动记的,"记录"本身不稀奇,徽章更奖励**整理**和**花钱习惯**。

**做:**

- 14 个徽章(§2),解锁后永久保留,记下解锁日期。
- 记录"哪天打开过 app",算连续天数。
- 统计页右上角的入口、徽章墙、详情卡片、解锁提示(§4)。
- 备份文件带上解锁记录和打开记录(§3)。

**不做:**

- 积分、等级、排行、分享。
- 系统推送通知、"快来记账"之类的催促。
- 自定义徽章、徽章图片素材(用系统 SF Symbols)。

## 2. 徽章与解锁规则

| id | 类别 | 名字 | 解锁条件 | 未解锁时的进度文字 |
|---|---|---|---|---|
| firstEntry | 起步 | 第一笔 | 至少 1 笔账 | 记下第一笔账 |
| firstAuto | 起步 | 自动驾驶 | 至少 1 笔自动账 | 设置一次自动入账 |
| firstBackup | 起步 | 未雨绸缪 | 导出过备份,或自动备份成功过 | 导出一次备份 |
| inboxZero | 整理 | 清清爽爽 | 有账单,且待归类为 0 | 待归类还有 N 笔 |
| tidyMonth | 整理 | 井井有条 | 某个已结束的月份,支出全部有分类且至少 10 笔 | 让一整个月的支出都有分类 |
| merchants10 | 整理 | 识途老马 | 商户记忆至少 10 个 | 记住了 N/10 个商户 |
| streak7 / streak30 / streak100 | 坚持 | 一周 / 一月 / 百日 | 连续 7 / 30 / 100 天打开过 app | 连续 N/7 天 |
| spendLess | 习惯 | 小有节余 | 某个已结束的月份,支出比上一个月少(上一个月有支出) | 等一个月比上月花得少 |
| spendLess3 | 习惯 | 稳扎稳打 | 连续 3 个已结束的月份,每月支出都比各自上月少 | 连续 N/3 个月 |
| entries100 / entries1000 | 里程碑 | 百笔 / 千笔 | 累计 100 / 1000 笔 | 还差 N 笔 |
| anniversary | 里程碑 | 一周年 | 最早一笔账的日期距今满一年 | 还差 N 天 |

- **已结束的月份**:本月不算,避免月初花得少就判为"比上月少"。比较跨年(1 月和上一年 12 月)。
- **连续打开**:按本地日期算,一天打开多次算一天;断一天从 1 重新计;已解锁的不收回。连续天数从今天往回数;今天还没算时(刚打开)以写入今天之后为准。
- **永久保留**:解锁记录写下就不再删除,数据变了也不收回;同一个徽章只记一条。

## 3. 数据

新增两个 SwiftData 实体(纯新增,轻量迁移):

| 实体 | 字段 | 说明 |
|---|---|---|
| `AchievementUnlock` | `id: String`(徽章 id)、`unlockedAt: Date` | 每个徽章最多一条 |
| `OpenDay` | `day: Date`(本地日期当天 0 点,存成 GMT 当天 0 点,和账单日期同一约定) | 每天最多一条 |

"导出过备份 / 自动备份成功过"沿用备份服务已有的 `lastExport`、`lastAutoBackup`。

**备份**:`BackupDocument` 增加两个**可选**字段 `achievements: [{id, unlockedAt}]?`、`openDays: [Date]?`。格式版本仍是 1:旧备份没有这两项照样能恢复(按空处理);旧版本 app 读到新文件会忽略多出的字段。恢复时整体替换这两类记录。

## 4. 界面

- **统计页入口**:标题栏右上角奖杯图标 + "6/14";有新解锁、还没看过的徽章时图标带小红点,进入徽章墙后消失("看过"的时间存在设置里)。
- **徽章墙**:按五类分组,每组三列网格。已解锁:彩色图标 + 名字 + "10月27日解锁";未解锁:灰色图标 + 名字 + 进度文字(§2)。点一个弹出详情卡片(解锁条件、解锁日期)。每类一个颜色。
- **解锁提示**:从顶部滑下的小提示"🏆 解锁:清清爽爽",轻震动,约 3 秒自动消失,点它打开徽章墙;一次解锁多个时只提示"解锁了 N 个徽章"。不推送系统通知。
- **何时检查**:打开 app / 回到前台(先写今天的打开记录)、记完一笔、导出或自动备份成功之后。
- **第一次升级**:已经满足条件的徽章一次性解锁,日期记为当天,只提示一次。

## 5. 测试方案

Swift Testing,SwiftData 用内存数据库。

- 每个徽章"刚好满足 / 差一点"。
- 连续天数:跨午夜、断一天重新计、一天多次只算一天。
- 月份比较:只算已结束的月份;跨年;上月没有支出时不算"比上月少"。
- 永久保留:解锁后删掉账单,再检查仍是已解锁;重复检查不会写第二条。
- 进度文字。
- 备份:导出带上两类记录,恢复后一致;没有这两项的旧备份照样能恢复。
- 模拟器:入口与"N/14"、红点、徽章墙、详情卡片、解锁提示、第一次升级的批量解锁。
